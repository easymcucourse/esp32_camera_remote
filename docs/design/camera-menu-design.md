# 设置菜单控制

`camera_menu` 为相机 socket 所有者使用的纯 C 模块，管理 Shutter、F-Number、ISO、EV、WB、Focus、Metering 七项主参数和九项扩展参数。方向键事件由 `gamepad_input` 产生，ATOM 轮询任务把当前选中项的步数交给相机任务；各项分别累加，移动光标不会把旧输入改投新参数。

## 输入与显示

- SETTINGS 中上下循环移动光标，左右选择相邻值；单方向按住 400 ms 后，每 150 ms 重复一次。多方向同时按住、换方向但未全松开、事件缺失、会话变化或切出 / 切入 SETTINGS 都要求先全松开。
- 普通参数枚举左右首尾循环，第一个按左到最后一个，最后一个按右到第一个；X 的 Focus 快捷切换和 Y 的 Mode 快捷切换保持循环。没有完整枚举的快门 / 光圈相对步进无法确定首尾，边界循环仍待协议支持。
- SETTINGS 前七行与 LIVE 相同，依次为 WIFI、FPS、CAM、FW、BATTERY、MODE、FOCUS。参数光标按画面顺序经过 Focus、Shutter、Aperture、ISO、EV、WB、Meter，再到 WI-FI、MAINTENANCE；属性 ID 保持原映射，初始选中 Focus。
- LCD worker 绘制光标背景及灰色只读项。实际参数保持回报值；有可计算目标时底部显示 `TO ...`，另显示 PENDING。终态在选中项底部保留 3 秒。
- UI 元数据通过短临界区整项复制，绘图与网络事务均不在该锁内。
- 参数页第九个导航项为 `WI-FI >`；A（DS4 叉）或右方向进入热点页。这不是相机参数，不投递 Sony 属性写入。热点页 A/B 和草稿规则见 [热点设计](wifi-ap-design.md)。
- 第十个导航项为 MAINTENANCE，开启需三秒内两次 A 确认停止取景；左右不会确认，不投递相机参数写入，见 [维护设计](maintenance-design.md)。

## 属性与目标

每次输入先刷新完整属性描述；只使用已验证数据集、预期标量类型、可写启用状态及第一个可选枚举。缺失、不完整、重复菜单描述、未知当前值或超过容量的枚举不授权写入。第二枚举含义尚未确认，不能用于绕过当前只读限制。

`setting_control` 保留实际值、最终目标和已发送目标：连续输入围绕最终目标合并；发出请求后等待相机回报已发送目标，才发后续目标。10 秒未回报则 TIMEOUT；拒绝、能力变化或安全取消清理待执行目标。signed EV 保持 16 位线格式，目标按有符号值显示。

快门 / 光圈若有枚举，使用相邻枚举的绝对值；若没有枚举但当前值有效且可写，则使用 ControlDeviceB 的 int8 单步。单步发送后，以当前属性沿请求方向变化作为完成证据；后续净步数合并并最多保留 64 步，不排队旧数据包。无有效当前值（例如 shutter `ffffffff` 或 aperture `fffe`）不发送。该路径不能显示尚未知的绝对目标值。

Sony ControlDeviceA 的模式 3 绝对值与历史 ControlDeviceB 相对步进存在机型差异，参照 [libgphoto2 的 Sony 参数实现](https://github.com/gphoto/libgphoto2/blob/master/camlibs/ptp2/config.c)；本项目的 B 单步线格式测试不等同于 ZV-E10 效果确认。需在实际可写快门 / 光圈状态下验证，进一步明确该机型的枚举或范围后完善绝对目标合并。

## 调度与安全

拍照、录像及释放动作在属性写入和取景事务前优先处理；属性读取期间新到的高优先级动作在下一次参数写入前再处理。每次写入前核对输入 generation，不匹配则取消全部菜单目标。

Mode 尚待回报时暂停其余参数写入；每个新属性快照最多发一个菜单参数，下一次写入必须有新的能力快照。存在待确认 / 待发送目标时，属性刷新间隔缩短至约 500 ms。Focus 菜单与 X 共用同一个目标状态，不产生两套相互覆盖的命令。

## 验证

主机测试覆盖真实裁剪快照的五项枚举、十六项合成枚举的左右首尾循环及待确认目标跨边界合并、底层非循环模式的末端夹紧、目标合并与旧回报、EV 负值线格式、只读 / 缺失 / 重复 / 截断描述、相对步进的等待 / 反向合并 / 拒绝 / 超时、断线清理及计时回绕。方向键测试覆盖界面隔离、首次按下、重复边界、多方向互锁、gap 与回绕。

仍需相机参数效果、快门 / 光圈协议、实际菜单视觉、终态显示时长、拍摄并发释放与帧率验收。全需求状态见 [实施清单](../development/implementation-status.md)。

## 扩展参数子菜单（2026-10-03）

ASPECT / MORE 入口通过 A 打开；ASPECT、DRIVE、EFFECT、DRO、AF AREA、WL FLASH、WB TEMP、WB AB RAW、WB GM RAW 共九项，属性代码沿用 camera_settings，使用完整描述中报告的整数类型、可写状态和第一枚举。无枚举、超64项、未知当前值或只读时不写入；类型变化取消待执行目标。完整枚举左右首尾循环，沿用目标合并、回读确认、拒绝和超时逻辑。EXIT 按 A 或 B 返回主设置页，Start返回LIVE，退出项不投递参数命令。原始WB微调值暂按十六进制显示，实机参数效果待验收。

当前诊断命令：`status` 显示录像 known/recording/pending；`extra status` 显示子菜单是否开启、选中ID及九项参数实际值、可写状态、状态码与目标。[2026-10-03 实测](../records/record-border-aspect-test-20261003.md)确认 Aspect 回读和视频模式录像红框/连续取景；其他扩展项未逐项写入验收。
