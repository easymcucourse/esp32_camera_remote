# カメラ接続

[English](../../en/user-guide/camera.md) · [简体中文](../../user-guide/camera.md) · **日本語**

現在の対象はSony ZV-E10です。Wi-FiによるPCリモートを有効にし、LCDのアクセスポイントへ接続します。SSIDとパスワードは接続画面で確認してください。保存済み設定が `common/network_config.h` の初期値より優先されます。

1. LCDを起動し、アクセスポイントの準備完了を確認します。
2. カメラでそのネットワークに接続し、ペアリング待機画面を開きます。
3. **ESP32-Camera-Remote** を許可します。初期化成功後にLCDのGUIDとカメラ識別情報を保存します。
4. 最初のフレームのデコード後にLIVEへ移ります。画像は1024×576、上下の余白は各12ピクセルです。Options/StartまたはUART `S` で768×432のSETTINGSプレビューに切り替えます。
5. `s` で停止、`j` で再開します。停止中の `p` はペアリングと再接続を診断します。

カメラIPはDHCPから取得し、`.2` に固定しません。未登録時はTCP 15740へ到達できる候補が一台の場合だけ選択します。複数の場合は余分なカメラを切断してください。登録後は保存済みカメラだけを選びます。通常のアプリ更新はNVSを保持しますが、消去すると識別情報を失います。

カメラを交換する場合はLCDを再起動し、起動画面のメンテナンスWebで確認付き全リセットを実行します。LCDのAP設定とUI設定も初期化しますが、ATOMの登録は保持します。UART `u` はありません。[開始手順](quick-start.md)を参照してください。

プロパティはイベントと約5秒の定期読み出しで更新します。`--` は未取得または値なし、未確認の列挙値は16進数です。WB色温度は保存値であり、現在使用中とは限りません。無線フラッシュとWB AB/GMは意味が未確認の場合、raw値を表示します。

現在のレンズはユーザー申告により **POWER_ZOOM** です。L1はWide、R1はTeleで、非電動ズームMF用の代替動作は無効です。RTはS1/S2のフォーカス・撮影段階、LT全押しは録画目標を要求します。応答成功だけで録画や設定変更の成立を判断せず、読み戻しとカメラ本体を確認します。

拒否された場合はカメラの許可を確認してから `j/p` を使用します。ネットワークエラーは1–30秒で再試行します。完全な `0x200F` 応答は同じセッションを再利用できます。直前の段階とトランザクションのログを保存してください。[障害対処](troubleshooting.md)、[操作](controller.md)、[現在の検証](../development/current-status.md)を参照します。過去の実測は最新未書き込みビルドの全動作を保証しません。
