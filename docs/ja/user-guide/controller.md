# コントローラーとジンバル

[English](../../en/user-guide/controller.md) · [简体中文](../../user-guide/controller.md) · **日本語**

ATOMはClassic DualShock 4を受信し、カメラ入力をI²C v2で送ります。BLEには特定記述子のUltimate 2解析があり、接続/電池取得だけで全実機マッピングやカメラ操作を確認したことにはなりません。[現在の状態](../development/current-status.md)を参照してください。

## 配線とペアリング

LCD SDA8/SCL9/GNDをATOM SDA26/SCL32/GNDへ接続します。100kHz、3.3Vプルアップ、アドレス0x42です。USB個別給電ではGrove5Vを接続しません。I²C v1→v2は両基板を更新します。

初回DS4はSHARE+PSを高速点滅まで長押しし、保存済みの場合はPSで起動します。MatrixのLCD接続灯とClassicコントローラー接続は別です。有効な入力レポートを準備完了の根拠とします。

## 操作

X/YはXbox配置名で、DS4の□/△に相当します。

| 入力 | 操作 |
| --- | --- |
| Start/Options | LIVE/SETTINGS切り替え |
| L1/R1 | Wide/Tele。明示的な非電動ズームかつMFの場合だけ近/遠フォーカス |
| Y/△ | 次の露出Mode。長押しで繰り返しません |
| X/□ | 次のフォーカスモード。長押し反復なし。実行中の肩ボタン操作を中止 |
| RT/R2 | 半押しS1、全押しS2。全押し解除でS2、完全に離してS1を解放 |
| LT/L2 | 半押し無動作。全押しの立ち上がりで確認済み録画状態から開始/停止を要求。離しても録画/フォーカスは変わりません |
| 方向キー上下 | 七設定、MORE、Wi-Fi情報を循環 |
| 方向キー左右 | 変更。列挙値は循環、EVは右増加/左減少 |
| A/× | 決定、MOREへ。Wi-Fiは情報のみ |
| B/○ | MOREから戻る。AP編集画面はありません |
| タッチパッド押下 | 現在は無動作。表示レベルは起動Webで保存 |
| 左スティック/L3 | ATOM内RS 3 Mini Pan/Tilt、本体原点復帰 |

肩ボタン/X/Y/トリガーのカメラ操作はLIVE/SETTINGS共通です。肩ボタン同時押しで停止し、両方を離すまで解除しません。方向キーは400ms後から150msごとに反復し、遅延pollで過去の反復をまとめて送りません。画面/入力源/セッション変更やgap後は、保持した方向を一度離します。

## 設定と確認

主メニューはShutter,F-Number,ISO,EV,WB,Focus,Meteringです。欠落/読み取り専用/無効な能力は灰色表示です。カメラ列挙値に従い、最新目標へ入力を合成し、読み戻し確認前に次目標を送りません。

シャッター/絞りは列挙があれば隣接値を選び、なければ有効な書き込み可能現在値を条件に単段コマンドを使います。変化確認ごとに1段だけ送り、拒否/時間切れで残りを削除します。非列挙単段コマンドはZV-E10実機検証が未完了です。現在値がなければ送りません。

`TO ...` は目標、属性行はカメラ実値です。`PENDING` は読み戻しまで続き、その後 `APPLIED` / `REJECTED` / `TIMEOUT` を短時間表示します。要求受理は物理適用ではありません。MOREは追加属性、Wi-Fiは現在情報のみです。編集/初期化/表示設定は起動Web保守で行い、コントローラー編集器はありません。

## ジンバル

RS 3 Miniをアクティベーション/バランス調整/軸解除し、Ronin Appを切断します。未保存時は唯一のMiniを選び、複数候補では選びません。保存対象は自動交換せず、交換時にATOM UARTで `gimbal pair` を実行します。再接続後は左スティック中央/L3解放が必要です。

新鮮な実Classic DS4のみが駆動します。LCD/入力源選択は独立し、UART SIMは実移動を禁止します。 `gimbal speed pan 120` / `gimbal speed tilt 240` は個別、 `gimbal speed 120` は両軸設定です。範囲20..400はプロトコル幅で、度/秒ではありません。NVSに保存します。スティック/L3と電源再投入復帰はユーザー確認済みです。本体原点復帰は任意原点記録ではなく、ソフトリミット/本体設定メニューは未実装です。正確な停止、中止、30分同時接続は未検証です。[プロトコル/制約](../design/rs3-mini-protocol.md)を参照してください。

## 制約

現在のレンズ申告はPOWER_ZOOMで、自動検出ではありません。非電動ズームMF代替は無効です。接続後はトリガーを一度離し、不明な録画状態を推測しません。切断/gap/セッション変更で古い操作を解放し、再接続で再送しません。Selectフォーカス枠、右スティック位置指定、R3枠中央復帰は未実装です。歴史、ソフトウェア、実機証拠を区別します。
