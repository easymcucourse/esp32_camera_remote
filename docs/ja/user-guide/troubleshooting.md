# トラブルシューティング

[English](../../en/user-guide/troubleshooting.md) · [简体中文](../../user-guide/troubleshooting.md) · **日本語**

設定を変更する前に、実行中のバージョン、モード、status、直前のエラーを保存します。[現在の状態](../development/current-status.md)では実装、ビルド、書き込み、物理動作、安定性を区別しています。

| 症状 | 確認・対処 |
| --- | --- |
| カメラ待機 | LCDのAPへの接続、DHCP、PCリモート、保存対象との一致を確認。 |
| 複数カメラ | 初回は目的のTCP 15740候補だけを接続。 |
| ペアリング拒否・識別変更 | カメラで許可。交換・再登録が必要な場合だけ起動Webの全リセットを使用。 |
| `0x200F` | 完全な応答とカメラモードを保存。一時的拒否の可能性があり、毎回永久切断と判断しない。 |
| 受付成功だが録画しない | 実録画状態の読み戻しと本体モードを確認。受付は録画成立ではない。 |
| 不明・不正な設定 | descriptor、書き込み可否、目標状態、読み戻しを確認。raw値を推測しない。 |
| LCD同期エラー | 危険なbufferへの書き込みを停止。限定回復と排出後の再起動のログ、heapを保存。 |
| ATOMオフライン・版不一致 | GPIO8/9 ↔ 26/32、共通GND、3.3Vプルアップ、`0x42`、両端v2を確認。 |
| DS4探索中 | 初回はSHARE+PS、保存済みはPS。HID接続だけでは入力準備完了ではない。 |
| BLE接続したが入力なし | 対応は採取したUltimate 2 descriptor/reportに限定。他のXbox BLEは未認定。 |
| ジンバル探索中 | Miniの電源と公式有効化、Ronin App切断、`gimbal status` を確認。既存登録を自動置換しない。 |
| 新しいジンバルを選ばない | `gimbal pair` で対象解除し、目的のMiniだけを起動。DS4登録は保持。 |
| 接続したが動かない | サービス・通知・中立初期化を待ち、PSを押し、stickとL3を離してから操作。SIM・古い入力は遮断。 |
| 速度不足 | `gimbal speed pan N` / `gimbal speed tilt N`、20–400。実測済みローカル値は120/240。 |
| 有効化要求 | 公式Ronin Appで有効化し、Appを切断してATOMへ再接続。 |

LCDを再起動し、起動接続画面からAPのアドレス（通常 `http://192.168.4.1/`）でメンテナンスに入ります。NORMAL移行後は入口を閉じます。PINやUART factoryはありません。APのみのリセットはカメラ識別を保持し、全リセットはLCD識別・UI・APを初期化しますがATOM登録は保持します。確認が必要で、失敗時は部分変更の可能性があります。NVS消去は通常更新ではなく、最終的な復旧操作です。

シリアルは115200、一ポート一プロセスです。記録終了は機器を停止しません。`--reset` は意図的な再起動です。rawログはignoredディレクトリへ保存し、公開する結論は匿名化します。[ログ](../development/serial-log.md)、[開始](quick-start.md)、[ジンバルプロトコル](../design/rs3-mini-protocol.md)を参照してください。
