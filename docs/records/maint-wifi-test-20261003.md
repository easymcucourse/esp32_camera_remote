# 2026-10-03 网页热点设置实测

本轮接入登录后的热点配置查询、SSID / 密码 / 信道修改与随机密码草稿。页面完全离线，留空密码保留当前值；接口不返回当前密码。需求目标不变，OTA / 重启 / 手柄维护入口仍待实施。

## 实现与证据

- `maint_json` 在 cJSON 前拒绝嵌套对象 / 数组、尾随数据和解码 NUL，限制 JSON 正文 512 字节；`maint_wifi` 用共用校验器处理部分字段，拒绝非整数信道及类型 / 重复 / 未知字段。
- 配置任务在响应前预留，完整发送响应后延迟 1500 ms 提交；发送失败取消，未提交任务 25 秒到期，未提交前不写 NVS 或重启驱动。查询返回最近异步任务状态，HTTP 200 仅代表排队成功。
- Wi-Fi 驱动重启尝试递增网络代数，后续登录 / 鉴权使旧令牌失效；维护模式与 PIN 保持。随机密码只生成草稿，不自动保存。
- 主机 45 / 45 项通过：`build/web-wifi-host-test.log`；LCD 开发与关闭模拟构建通过：`build/web-wifi-probe-build.log`、`build/web-wifi-release-build.log`。开发固件 COM8 烧录成功：`build/flash-web-wifi.log`；保留 NVS，ATOM 未重新烧录。

## 设备测试

`maint-wifi.uart` 五条串口命令通过，开发探测任务用热点自身 IP 上的 TCP / HTTP 执行 38 个请求：基础登录 / 信息 / 会话轮换 / 登出 / 退出；热点接口未登录 401；查询不含当前密码；随机草稿未保存；十个无效输入 400；空修改不重启；临时修改三个网络字段、成功应用、旧令牌失效、原 PIN 重新登录；恢复原配置后再次作废旧令牌并重新登录。结果 `passed=38 transport=loopback restored=1`，见 `build/maint-wifi-test.log`。没有打印密码、PIN 或令牌。

基础维护脚本额外两轮各 14 个请求通过：`build/maint-wifi-basic-regression.log`。受控硬件复位后读取热点配置，确认原信道与密码长度、默认密码标志，以及 full / SIM0；关闭维护成功：`build/maint-wifi-reset-final.log`。第一次复位脚本错误地期待 status 中不存在的 `maint=0` 字段，脚本超时；纠正断言后通过，无对应固件故障。

最终相机自动连接开启、session=0 等待已配对相机；维护关闭。设备复位后的内部 RAM 样本约 55 KiB，不代表长期最低值。原始本机日志可能包含设备身份，保持 Git 忽略，不复制到正式记录。
