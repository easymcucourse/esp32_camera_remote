# 2026-10-03 默认密码标签回归

连接页密码旁绘制黄色 DEFAULT，热点菜单 PASS 行保留同样标签。实际密码等于出厂密码时显示，与 SSID、信道和密码显示开关无关；隐藏密码时也保留标签。判断在 wifi_config，UI 通过独立布尔字段取得状态，避免比较已经掩码的显示字符串。状态与字符同锁发布，标签变化单独触发重绘。

40 / 40 主机测试通过，扩展已有 wifi_config 回归：修改 SSID、关闭显示仍是默认密码，自定义密码不再提示。LCD 构建与 COM8 / 460800 烧录成功，未擦除 NVS；ATOM 未重烧。

14 条串口命令通过：保存原密码 / 显示状态，默认密码标签为 1，关闭密码显示后仍为 1，自定义密码后为 0，最后恢复并核对原密码及开关。相机 session=0，Wi-Fi 参数切换正常完成；明文密码及带密码的发送行在保存证据前脱敏。正式记录不保存密码。

证据：`build/default-host-test.log`、`build/default-lcd-build.log`、`build/flash-default-label.log`、`build/wifi-default-label-test.log`。本地一次性验证程序位于忽略的 build 目录，使用 finally 恢复原设置，未提供会覆盖用户配置的固定密码回放脚本。

验证只证明逻辑判断、状态发布与参数转换；没有观察物理屏幕，标签颜色 / 位置和热点菜单视觉继续待验收。全需求中的信息档位、对焦框、BLE 手柄、维护 OTA、CI / 稳定性等未完成。
