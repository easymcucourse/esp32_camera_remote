# 手柄控制方案

手柄经 M5Stack ATOM Matrix 接收后通过 I²C 上报 LCD（见 [ATOM 子项目](../../m5_atom_matrix/README.md) 和 [I²C 通信协议](../design/i2c-protocol-design.md)）。分类见[文档总览](../README.md#适配目标)：蓝牙链路分传统蓝牙与 BLE，输入报告分 Sony 兼容与 Xbox 兼容，两个维度独立，报告不能共用解析器。

当前固件只实现传统蓝牙、Sony 兼容的 DualShock 4。八位堂猎户座 2 代（BLE、Xbox 兼容）是适配目标，尚未实现；下文的按键动作对两类手柄相同。左摇杆和 L3 由 ATOM 直接控制云台，不上报 LCD。本文按 Xbox 布局命名按键，与 Sony 兼容手柄的对照如下：

| 本文名称 | DS4 按键 | 位置 / 类型 |
| --- | --- | --- |
| LT / RT | L2 / R2 | 模拟扳机，0–255 |
| LB / RB | L1 / R1 | 肩键 |
| Select | Share | 左上小键 |
| Start | Options | 右上小键 |
| 方向键 | 方向键 | 十字键 |
| A / B / X / Y | ✕ / ○ / □ / △ | 右侧四键，下 / 右 / 左 / 上 |
| 左摇杆 / 右摇杆 | 左摇杆 / 右摇杆 | -128..127 |
| L3 / R3 | L3 / R3 | 摇杆按下 |

当前代码已实现：Start 切换界面、LB/RB 切换曝光 Mode，以及 LIVE+MF+变焦不可用时 X/Y 手动对焦（新增功能待烧录后实机验收）。其余功能为设计方案；标注“待抓包确认”的 Sony 命令需先用 Imaging Edge Remote 抓包并在 ZV-E10 上验证。

## 界面模式

界面分 LIVE（全屏取景）和 SETTINGS（缩略图 + 参数菜单）两种，画面布局、状态栏和提示信息见 [界面显示方案](ui-request.md)。

界面模式与相机对焦模式相互独立：

- Start 只切换 LIVE / SETTINGS，不修改相机 AF/MF。
- AF/MF 通过设置菜单的 `Focus` 项修改，也可能由相机机身改变；以相机回报为准。
- Select 仅在相机处于 MF 时打开 / 关闭手动对焦框，不切换对焦模式。

```mermaid
stateDiagram-v2
    [*] --> LIVE
    LIVE --> SETTINGS: Start
    SETTINGS --> LIVE: Start
```

```mermaid
stateDiagram-v2
    [*] --> AF
    AF --> MF_BOX_OFF: 菜单 Focus 改为 MF
    MF_BOX_OFF --> AF: Focus 改为 AF
    MF_BOX_OFF --> MF_BOX_ON: Select
    MF_BOX_ON --> MF_BOX_OFF: Select
    MF_BOX_ON --> AF: Focus 改为 AF（自动关闭对焦框）
```

## 扳机（LT / RT）

DS4 扳机为模拟量，分两档并带迟滞防抖：

| 档位 | 进入 | 退出 |
| --- | --- | --- |
| 半压 | ≥ 30% | < 20% |
| 全压 | ≥ 90% | < 80%（回到半压） |

**RT 拍照**

1. 半压：S1 按下，相机对焦。
2. 全压：S2 按下，拍照；保持全压时是否按驱动模式连拍需实机确认。
3. 退回半压：S2 释放。
4. 完全松开：S1 释放。

**LT 录像**

1. 半压：S1 按下，相机对焦。
2. 每次从非全压进入全压：根据相机确认的录像状态请求相反目标；未录像发送 `0x9207(0xD2C8)` 的 u16 值 2，录像中发送值 1。状态未知或已有待确认请求时不重复发送，并提示等待状态确认。这是显式开始/停止，不能把值 1 当作紧随开始的按键释放。
3. 完全松开：S1 释放。

录像状态以相机属性为准。

**安全规则**

- LT、RT 共用相机 S1：`S1 = LT半压 或 RT半压`，只在合并状态变化时发送，避免松开一个扳机误释放另一个的 S1。
- 手柄连接后必须先观察到 LT、RT 都完全松开，才允许拍照或录像。
- 手柄断开、ATOM I²C 超时、相机断开或任务重启时立即清空扳机状态，并释放已按下的 S1/S2；重连后不得重放旧命令。
- 拍照、录像和释放命令走高优先级队列，在每帧取景读取前优先处理。

## 曝光 Mode（LB / RB）

在相机返回的曝光 Mode 枚举中循环切换上一个 / 下一个（属性 `0x500E`，通过 `0x9205` 写入，已实现）。

- 可选值以相机实际返回为准。
- 回读确认后才视为生效；相机拒绝（例如录像中）时保持原值。
- 已知限制：相机返回成功后约 5 秒属性才更新，连续快速按键需改为“合并到最终目标、生效后再发下一次”。

## 手动对焦框（Select + 右摇杆）

仅当相机回报为 MF 时有效。红框为相机当前对焦位置，绿框为右摇杆正在移动的目标点，显示规则见 [界面显示方案](ui-request.md#手动对焦框规划)。

- **Select**：MF 下打开 / 关闭对焦框；AF 下无操作。
- **右摇杆**：移动绿框。速度与摇杆偏移量成正比，中心设死区，移动到画面边缘时限位。
- **R3**：绿框回到画面中心，仅在对焦框开启时有效；与右摇杆移动一样按下方规则自动提交。按 R3 时右摇杆偏移量不计入移动，避免按下时误推摇杆。
- **提交**：右摇杆回中（或按 R3）后 300ms 无新移动，自动把绿框位置发送给相机。
- **模式变化**：相机切换为 AF 时自动关闭对焦框。
- **待验证**：MF 下相机是否接受对焦位置属性（预计 `0xD2DC`）。

## 设置模式（方向键）

| 菜单项 | 相机属性 | 修改方式（待抓包确认） |
| --- | --- | --- |
| Shutter 快门 | `0xD20D` | 步进 ±1 |
| F-Number 光圈 | `0x5007` | 步进 ±1 |
| ISO | `0xD21E` | 枚举写值 |
| EV 曝光补偿 | `0x5010` | 枚举写值 |
| WB 白平衡 | `0x5005` | 枚举写值 |
| Focus 对焦模式 | `0x500A` | 枚举写值 |
| Metering 测光 | `0x500B` | 枚举写值 |

- **上 / 下**：移动参数光标，到首尾循环；仅在 SETTINGS 有效。
- **左 / 右**：修改当前参数为上一个 / 下一个值。按住 400ms 后开始重复，重复命令只保留最新目标值。
- 当前曝光 Mode 下不可修改的项（例如 P 模式的光圈）左右无效。
- 相机确认并回读后才视为生效；拒绝、超时或断线时恢复原值。菜单显示见 [界面显示方案](ui-request.md#设置菜单)。

## 左摇杆（云台）

所有模式下均控制云台，不与其他功能冲突。左摇杆和 L3 在 ATOM 内部处理，ATOM 直接向 BLE 云台发送命令，不上报 LCD；LCD 只显示云台连接状态，LCD 断开不影响云台。详见 [I²C 通信协议](../design/i2c-protocol-design.md#云台本地控制)。

- X 轴：水平转动（Pan）；Y 轴：俯仰（Tilt）。
- 中心死区约 10%，速度曲线采用二次方，小幅推杆便于微调。
- 漂移校准、软限位和启用开关保存在 ATOM，入口在 ATOM 本地实现。
- 手柄断开或输入超时（建议 200ms）必须立即停止云台。

**L3 云台回中**：所有模式下有效，云台以限速平滑转回 Pan / Tilt 零位（上电或校准时记录的位置）。回中过程中推动左摇杆立即取消回中，恢复手动控制；按下 L3 时左摇杆偏移量不计入，避免按压时误推。

## 右侧四键

布局：A（✕）下、B（○）右、X（□）左、Y（△）上。

### 变焦（A / B）

所有模式下有效，按住持续变焦，松开停止。

| 按键 | 方向 |
| --- | --- |
| A（✕） | Tele（拉近） |
| B（○） | Wide（拉远） |

- 按下发送变焦开始，松开发送停止（`0xD2DD` ZoomOperation，INT8：正值 Tele、负值 Wide、0 停止，速度范围待抓包确认）。
- A、B 同时按下时立即停止变焦，两键都松开后才接受新的变焦。
- 手柄断开、ATOM I²C 超时、相机断开时必须立即发送停止，与扳机安全规则同等优先级；停止命令走高优先级队列。
- 变焦可用性以相机回报为准（`0xD25B` ZoomEnableStatus）：电动变焦镜头（如 E PZ 16-50mm）为光学变焦；其他镜头取决于相机是否开启清晰影像变焦 / 数字变焦。不可用时按键无效。

### 对焦放大（X）

LIVE 下有效，用于检查对焦；满足下文 X/Y 手动对焦条件时，X 不触发放大。

- 每按一次 X 按相机支持的倍率循环：关闭 → 第一级 → 第二级 → 关闭（可选倍率和当前倍率以相机回报 `0xD22F` 为准，不写死）。
- 放大位置：MF 且对焦框开启时以绿框位置为中心；其他情况以红框（当前对焦点）为中心，无对焦点信息时以画面中心。
- 放大期间移动绿框或按 R3，放大区域跟随移动。
- 按 Start 进入 SETTINGS 时自动退出放大。
- 相机机身设置“放大时自动对焦”为关闭时，半压 LT/RT 会退出放大；放大状态以相机回报（`0xD22D`）为准。放大画面的显示见 [界面显示方案](ui-request.md#对焦放大规划)。
- 协议：第 3 版协议下已捕获 `0x9205(0xD254)` 的 8 字节负载并返回 OK，但内部倍率/坐标布局及实际效果尚未确认，不直接命名字段。旧方式 `0xD2CB` / `0xD2CC` 和 `0xD2CD`–`0xD2D0` 仍为待验证备选。

### 屏幕信息显示（Y）

LIVE 下有效，每按一次在全显 / 精简 / 隐藏三档间循环，不向相机发送命令；满足 X/Y 手动对焦条件时不切换信息显示。各档内容见 [界面显示方案](ui-request.md#屏幕信息显示档位规划)。

### 无变焦时的手动对焦（X / Y）

- 启用条件：LIVE、相机明确回报 MF、变焦能力已确认不可用。“无变焦”指能力不可用，不是当前未按变焦键；能力或对焦模式未知时不启用。无需打开对焦框。
- X（□）近对焦、Y（△）远对焦；同一次输入只执行一种功能，不同时触发放大或信息显示。用户已确认正值向近处，代码发送 X=+1、Y=−1；其余镜头/相机需另行验证。
- `0x9207(0xD2D1)` 使用 2 字节有符号小端值，已捕获 +1/+3/+7/−3/−7 并返回 OK。单击规划为最小档一步；按住 400 ms 后每 150 ms 重复一次（暂定节奏），不积压步进命令、不按下即补发大量步数。
- X+Y 同时按下停止重复，两键都松开后重新解锁。松开、切 AF、变焦能力变化、进入 SETTINGS 或断线时清除重复状态及未执行步进；条件恢复后必须先松开再按，不将旧按键重新解释为其他功能。

## 输入处理规则

- 按键只在“按下边沿”执行一次性操作；ATOM 事件队列已保证短按不丢失并按事件 ID 去重。
- 摇杆和扳机使用最新状态快照，不把每个 HID 报告排入命令队列。
- 位置类命令（对焦框、放大区域；云台在 ATOM 内）限速约 5 次/秒，参数类命令合并到最新目标。
- 同时按下互斥键（如 LB+RB、方向键左+右）时忽略；A+B 同时按下时停止变焦。

## 验收测试

上述协议证据见 [2026-10-01 三轮抓包分析](../records/protocol-analysis-20261001.md)。已捕获不等于固件已实现；未完成释放、状态回读及方向验证前，不宣称拍照/录像/对焦控制已完整验收。

- LT/RT 单独按压、同时按压、交叉释放、带压连接、蓝牙断线，不得误拍或遗留 S1/S2。
- 拍照单张、连拍、录像开始 / 停止；录像中切换曝光 Mode 被拒绝时有正确反馈。
- AF/MF 由菜单和相机机身切换时，Select 只控制对焦框；切到 AF 时对焦框自动关闭。
- 绿框停止移动 300ms 后自动提交。
- A/B 按住变焦、松开停止；A+B 同时按下、手柄断开、ATOM 断开时变焦立即停止；相机不可变焦时按键无效。
- LIVE+MF+变焦确认不可用时 X/Y 仅近/远对焦；单击一步、长按限速重复、两键同按无动作；按用户确认的正值近、负值远实机验收。
- 其他 LIVE 条件下 X 循环放大、Y 循环信息档位；对焦模式/能力变化时旧按键必须先释放，避免误触发新映射；SETTINGS 不启用 X/Y 对焦。
- 云台在手柄断开、手柄输入超时时立即停止；LCD 断开或 I²C 断开时云台仍可由手柄控制。
- L3 回中在各模式下有效，回中途中推左摇杆可立即取消。
- R3 只移动绿框到中心，提交前红框不变；对焦框关闭或 AF 下按 R3 无操作。
- Wi-Fi 断线、相机重启、命令超时后，旧命令不会在重连时执行。
