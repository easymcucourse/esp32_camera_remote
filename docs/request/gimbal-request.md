# BLE 云台控制需求

[English](../en/request/gimbal-request.md) · **简体中文** · [日本語](../ja/request/gimbal-request.md)

本文定义通过 DualShock 4 左摇杆控制 BLE 云台的用户可见行为及验收标准。实现方案见 [BLE 云台控制设计](../design/gimbal-design.md)。

> 2026-10-10：已接入 RS 3 Mini 第三方 BLE 协议、真实 DS4 左摇杆、原生 L3 回中与安全停止。下文仍是完整目标；软件/实机边界见 [当前实现](../design/rs3-mini-protocol.md)。任意零位、软限位和板载设置菜单尚未实现；原生回中的取消与停止时延需实测。

## 范围

- 云台由 M5Stack ATOM Matrix 通过 BLE 直接控制，左摇杆和 L3 在 ATOM 内部处理，不经过 LCD。
- LCD 只显示云台连接状态，不参与云台位置、速度、回中和校准。
- 不包括：云台跟随、轨迹录制、定时摄影、通过相机画面自动跟踪。

## 前置条件

- 取得大疆 RS 3 Mini 的 BLE 控制协议（官方文档或抓包）。型号已确定。
- ATOM 蓝牙改为双模（Classic + BLE），且 DS4 与云台可以同时稳定连接，见 [Matrix LED 状态显示设计](../design/matrix-led-design.md#bluetooth-双模限制)。

## 需求

### 1. 连接

- **R1.1** ATOM 上电后自动搜索并连接已保存的云台；没有保存记录时进入配对流程（入口见 R5.1）。
- **R1.2** 只有控制服务和写入通道都可用时才视为已连接；仅建立 BLE 链路不算已连接。
- **R1.3** 云台连接状态在 ATOM 灯阵右下角 `(4,4)` 用紫色显示（规则见 [Matrix LED 状态显示需求](matrix-led-request.md)），并上报 LCD 显示为“未连接 / 搜索中 / 连接中 / 已连接”。
- **R1.4** 云台断开后自动重连，不需要重启 ATOM。

### 2. 摇杆控制

- **R2.1** 左摇杆 X 轴控制水平转动（Pan），Y 轴控制俯仰（Tilt），所有界面模式下都有效。
- **R2.2** 中心死区约 10%；速度随摇杆偏移量按二次方曲线增加，小幅推杆便于微调。
- **R2.3** 摇杆松开回中后，云台在 100 ms 内停止（待实测）。
- **R2.4** 云台控制命令最多约 5 次/秒，只发送最新目标，不排队积压。

### 3. 回中

- **R3.1** 按下 L3 时，云台以限速平滑转回零位（上电或校准时记录的位置）。
- **R3.2** 回中过程中推动左摇杆立即取消回中，恢复手动控制。
- **R3.3** 按下 L3 时左摇杆的偏移量不计入，避免按压时误推。

### 4. 安全停止

- **R4.1** 以下情况必须立即发送停止命令：DS4 断开；DS4 输入超过 200 ms 未更新；云台连接断开后重连成功时（先停止，再接受新输入）。
- **R4.2** LCD 断开、LCD 重启或 I²C 收到非法帧时，云台继续按手柄输入工作。
- **R4.3** 写入云台连续失败时，显示云台故障（灯阵和 LCD），并停止发送运动命令直到恢复。

### 5. 本地设置

- **R5.1** 配对、漂移校准、零位记录、软限位和启用开关在 ATOM 本地操作（例如板载按键长按进入），不经过 LCD。
- **R5.2** 以上设置保存在 ATOM 的 NVS 中，断电后保持。
- **R5.3** 关闭启用开关后，左摇杆和 L3 不再控制云台，云台连接灯熄灭。
- **R5.4** 软限位生效时，云台不超出设定的 Pan / Tilt 范围；到达限位后继续推杆无动作。

## 验收测试

- 冷启动后自动连接已保存云台，灯阵紫灯常亮，LCD 显示已连接。
- 左摇杆小幅推动时云台缓慢转动，推到底时最快；松开后在 R2.3 时间内停止。
- 按 L3 云台平滑回中；回中途中推摇杆立即取消。
- 手柄关机、手柄静止超过 200 ms 无报告时，云台立即停止。
- 拔掉 LCD 与 ATOM 之间的 I²C 线，云台仍可由手柄控制。
- 云台断电后紫灯进入搜索节奏，重新上电后自动重连，重连后不执行旧的运动命令。
- 设置软限位后反复推到边界，云台不越界。
- DS4 与云台同时连接连续运行 30 分钟，无断连、无失控转动。

## 待确认问题

1. 第三方DUML协议已接入，用户确认基础摇杆/L3和Pan120/Tilt240正常；精确停止时延、回中取消和全部界面仍需验收。
2. 本台出现官方激活提示后，用户通过Ronin完成激活并恢复控制；首次使用须按官方流程激活，不推断历史可运动代表已激活。
3. DS4（Classic）与云台（BLE）并发时，DS4 输入延迟和稳定性是否满足要求。
4. 校准和软限位的本地操作方式（按键组合、灯阵提示）。
