# 项目修改清单

本文汇总当前项目审查结果，按优先级列出建议修改项。完成一项后可将对应的 `- [ ]` 改为 `- [x]`。

2026-10-01 连接补齐：以下勾选表示代码与主机回归通过；固件已烧录，动态发现、配对保存、取景、停止与 LCD 重启恢复已实测，见 [连接验收](../records/connection-test-20261001.md)。热点重启后的 DHCP 恢复仍需关注，完整故障注入尚未完成。

## 已核实但暂不列为当前缺陷

- `camera_model` 和 `camera_firmware` 当前只在 JPEG 工作任务启动前更新，现有执行路径下未确认存在数据竞争；如果以后支持运行中更新，则需要同步保护。
- PSRAM 120MHz 已在当前设备上通过实测，但仍属于实验性配置，应作为兼容性和长期稳定性风险继续验证。
