# 维护页面需求

本文定义 LCD 主机在自身热点上提供的网页维护页面：用手机或电脑连接热点后，通过浏览器查看设备信息、修改热点 SSID 和密码、上传新固件（OTA）。目的是在没有 USB 线和 ESP-IDF 环境时也能更新固件和修改热点配置。

> 草案：本文的功能均未实现。当前分区表没有 OTA 分区，固件只能通过 USB 烧录。

## 范围

- 包括：LCD 固件的维护模式、网页登录、设备信息、热点 SSID / 密码 / 信道设置、LCD 固件 OTA、重启。
- 不包括：ATOM 固件更新（ATOM 不使用 Wi-Fi，仍通过 USB 烧录）；从互联网自动检查更新；相机控制和取景预览。

## 需求

### 1. 维护模式

- **R1.1** 维护页面默认关闭。只有在设备上主动开启维护模式后，才启动网页服务。
- **R1.2** 开启入口：连接页上的手柄操作（相机未连接时）；手柄设置菜单中的 `MAINTENANCE` 项（取景中）；串口命令 `maint on`。
- **R1.3** 开启后 LCD 连接页显示访问地址（`http://192.168.4.1/`）、6 位一次性 PIN 和剩余时间。
- **R1.4** 无操作 10 分钟后自动关闭；也可以通过菜单、串口 `maint off` 或网页上的“退出”按钮关闭。重启后维护模式总是关闭。
- **R1.5** 维护模式与相机会话互斥，网页服务不与取景同时运行，避免占用 Wi-Fi 带宽、CPU 和内部 RAM：
  - 维护模式开启期间，相机照常可以连接；相机会话一旦建立，立即关闭维护模式和网页服务，LCD 提示 `MAINTENANCE OFF: camera connected`。
  - 取景中开启维护模式时，先停止取景（需要二次确认），再开启维护模式；此时相机暂停自动重连，维护模式关闭后自动恢复连接相机。
  - 固件上传期间（R5）不关闭维护模式，相机连接保持停止。

### 2. 登录

- **R2.1** 进入网页时必须输入 LCD 上显示的 PIN。PIN 每次开启维护模式时重新生成。
- **R2.2** 连续 5 次输入错误后，锁定 60 秒并生成新的 PIN。
- **R2.3** 同一时间只允许一个已登录的会话；新会话登录后旧会话失效。
- **R2.4** 维护模式关闭时所有会话失效。网页检测到连接断开时提示“维护模式已关闭（可能因相机已连接）”。

### 3. 设备信息

- **R3.1** 显示：固件版本、编译时间、当前运行的分区、ESP-IDF 版本、运行时间、内部 RAM 与 PSRAM 余量、热点客户端列表（MAC、IP、RSSI）、相机与 ATOM 连接状态。

### 4. 热点设置

- **R4.1** 支持修改 SSID、密码和信道，校验规则与 [Wi-Fi 热点需求](wifi-ap-request.md) 的 R2.2 相同；不合法时在网页上提示原因，不保存。
- **R4.2** 网页不显示当前密码，只显示密码长度；新密码输入框可切换明文显示。提供“生成随机密码”按钮。
- **R4.3** 保存前提示“热点将重启，当前网页连接会断开，请用新的 SSID 和密码重新连接”；保存成功后热点按 Wi-Fi 热点需求的 R2.4 重启。
- **R4.4** 热点重启后维护模式保持开启，用新参数重新连接后可以继续使用（需要重新登录）。

### 5. 固件更新（OTA）

- **R5.1** 在网页上选择 `.bin` 文件上传，显示上传进度；LCD 同时显示 `UPDATING xx%`。
- **R5.2** 只接受本项目 LCD 固件：芯片型号、项目名称不符或镜像校验失败时拒绝，并提示原因。ATOM 固件和其他项目的固件必须被拒绝。
- **R5.3** 上传前显示文件中的固件版本和编译时间，与当前版本对比；版本相同或更旧时提示，但允许继续。
- **R5.4** 开始上传时停止取景并安全释放所有手柄动作（S1、S2、变焦）。
- **R5.5** 上传失败、中断或校验失败时，设备继续运行当前固件，不重启，网页和 LCD 提示原因，可以重新上传。
- **R5.6** 上传成功后自动重启进入新固件。新固件启动失败或启动后 60 秒内复位时，自动回退到旧固件。
- **R5.7** OTA 不改变 NVS 中的热点配置和相机配对身份。

### 6. 其他

- **R6.1** 网页提供“重启设备”按钮，需要二次确认。
- **R6.2** 网页所有资源都内置在固件中，不依赖互联网（热点没有外网）。
- **R6.3** 网页适配手机竖屏和电脑浏览器。

## 验收测试

- 未开启维护模式时访问 `http://192.168.4.1/` 无响应。
- 相机未连接时开启维护模式，然后让相机加入热点：相机会话建立后网页立即无法访问，LCD 提示维护模式已因相机连接关闭，取景帧率与未开启维护模式时相同。
- 取景中从设置菜单开启维护模式：确认后取景停止，网页可用，相机不自动重连；退出维护模式后相机自动恢复取景。
- 开启后 LCD 显示地址、PIN 和倒计时；10 分钟无操作后自动关闭，网页请求返回未登录。
- 输入错误 PIN 5 次后锁定 60 秒，LCD 上的 PIN 变化。
- 第二台设备登录后，第一台设备的操作返回未登录。
- 网页修改 SSID 和密码后，热点按新参数重启；手机重新连接并登录后，维护模式仍开启；相机用新参数连接后无需重新配对。
- 输入 7 位密码、33 字节 SSID 时网页提示原因，热点不重启。
- 上传正确的 LCD 固件：进度正常，自动重启后版本号变化，相机配对和热点配置不变。
- 上传 ATOM 固件、随意截断的 `.bin`、其他文本文件：均被拒绝，设备不重启。
- 上传过程中断开手机 Wi-Fi：设备继续运行旧固件，可再次上传。
- 上传一个启动后故意复位的测试固件：设备自动回退到旧固件。
- 上传开始时 RT 处于全压：S2、S1 被释放。
