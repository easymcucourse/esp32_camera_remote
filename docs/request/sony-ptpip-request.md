# Sony 相机连接需求

本文定义 LCD 主机与 Sony 相机之间连接、取景、属性读取和相机控制的用户可见行为及验收标准。实现方案见 [Sony PTP/IP 客户端分层设计](../design/sony-ptpip-design.md)，协议事实见 [通信分析与实测记录](../records/protocol-analysis.md) 和 [2026-10-01 抓包分析](../records/protocol-analysis-20261001.md)。当前连接流程及代码边界集中在 [设计的当前实现部分](../design/sony-ptpip-design.md#当前实现连接与运行)。

> 草案：标注“已实现”的条目与当前固件一致；其余为目标需求，数值类指标需实测后确认。

## 范围

- 目标相机：Sony ZV-E10（固件 2.00 起），通过 PC 远程（PTP/IP，TCP 15740）连接到 LCD 创建的 Wi-Fi 热点。
- 包括：相机发现、配对、重连、实时取景、属性读取、曝光 Mode 等参数设置、拍照和录像。
- 不包括：Wi-Fi 热点本身的配置（见 [Wi-Fi 热点需求](wifi-ap-request.md)）、手柄按键分配（见 [手柄控制方案](gamepad-request.md)）、界面布局（见 [界面显示方案](ui-request.md)）。

## 需求

### 1. 相机发现

- **R1.1**（已接入，待实机验收） 不写死相机 IP 和 MAC。相机加入热点后，从 DHCP 租约表取得地址，并探测 TCP 15740 端口。
- **R1.2**（已接入，待实机验收） 未配对时只选择唯一可达候选，完整 Sony 初始化成功后才保存其 MAC 和相机 GUID。
- **R1.3**（已接入，待实机验收） 已配对时只连接已记录的相机；其他客户端（例如手机）加入热点不得干扰连接。
- **R1.4**（已接入，待实机验收） 有多个可连接的 15740 端口且没有配对记录时，界面提示“只连接一台相机”，不随机选择。

### 2. 配对与重连

- **R2.1**（已实现）首次连接时，相机上显示 **ESP32-Camera-Remote** 的确认提示；用户确认后保存配对身份。
- **R2.2**（已实现）设备身份（GUID）在断电和常规烧录后保持不变，相机无需重新配对。
- **R2.3** 已配对的相机重连时不显示“请在相机上确认”，从相机加入热点到出现第一帧不超过 10 秒（待实测确认）。
- **R2.4**（已接入，待实机验收） 相机拒绝连接（InitFail）时，界面显示失败原因并提示用户在相机上重新进入配对等待画面；不得无限快速重试。
- **R2.5**（已接入，待实机验收） 提供清除配对身份的入口，清除后下次连接按首次配对处理。

### 3. 实时取景

- **R3.1**（已实现）第一帧成功显示后自动进入取景，上下各留 12 像素黑边。
- **R3.2** 全屏取景帧率在当前 Wi-Fi 条件下不低于 3.5 FPS，设置界面不低于 2.4 FPS；重构和新增功能不得使帧率下降。
- **R3.3** 连续运行 30 分钟，内部 RAM 和 PSRAM 最低剩余值稳定，不出现持续下降。
- **R3.4** 单帧损坏只丢弃该帧，不中断取景；连续损坏或显示失效时自动恢复，恢复失败才重连或重启。

### 4. 停止与恢复

- **R4.1**（网络取消已接入，1 秒整机指标待实测） 串口 `s` 或界面停止操作在任何阶段（包括等待配对确认）都在 1 秒内生效，关闭会话并保留最后画面。
- **R4.2**（已实现）`j` 恢复取景时复用已保存身份，不需要重新配对。
- **R4.3** 同一时刻只运行一个相机连接；重复请求被忽略并记录日志。

### 5. 断线恢复

- **R5.1** 相机断电、离开热点或网络中断后，界面返回连接页，并显示最近一次失败原因。
- **R5.2**（已接入，待实机验收） 自动重连使用有上限的指数退避：网络失败从 1 秒开始，最长 30 秒；配对被拒绝时等待用户操作，不自动重试。
- **R5.3**（已接入，待实机验收） 断线时清除所有未执行的相机命令，重连后不得执行旧命令。

### 6. 属性读取

- **R6.1**（已实现）显示曝光模式、ISO、快门、光圈、EV、白平衡、对焦、测光和闪光。`--` 表示相机报告无值或尚未取得数据，未收录的枚举显示原始十六进制。
- **R6.1a**（已接入，待实机验收）增加画幅、驱动模式、照片效果、DRO、对焦区域、无线闪光、白平衡色温及 AB/GM 微调显示；未确认的枚举与微调编码保留原始值，不能套用截图状态。
- **R6.2**（事件刷新已接入，1 秒指标待实测） 相机机身上修改参数后，界面在 1 秒内更新（依靠属性变化事件）；没有事件时最迟 5 秒更新。
- **R6.3** 属性数据解析失败只影响该次刷新，不中断取景。

### 7. 相机控制

- **R7.1** 设置类命令（曝光 Mode、ISO、快门、光圈、EV、白平衡、对焦模式）发送后，界面依次显示 `PENDING`、`APPLIED` / `REJECTED` / `TIMEOUT`，不把“已发送”显示为“已生效”。
- **R7.2** 连续快速操作合并为最终目标值，不积压基于旧值计算的请求。
- **R7.3** 拍照支持 S1 半按、S2 全按，并按正确顺序释放；录像开始和停止以相机回报的录像状态为准。
- **R7.4** 拍照、录像、释放和变焦停止命令优先于取景读取执行。
- **R7.4a**（已接入，待实机验收）LIVE、MF 且相机确认变焦不可用时允许 X/Y 对焦；正值向近处、负值向远处。每步前重读能力；状态变化或停止时取消旧命令。
- **R7.5** 相机不支持或拒绝某项操作时显示明确反馈，不修改界面来假装成功。

### 8. 健壮性

- **R8.1** 相机发送异常、截断或超长数据时不崩溃、不越界，断开后按 R5 重连。
- **R8.2** 所有失败在串口日志中记录阶段、操作码、事务号和错误类型。

## 验收测试

- 首次配对：相机提示确认，确认后出现画面；断电重启两端后无需再次确认。
- 已配对重连：从相机加入热点到第一帧的时间符合 R2.3。
- 配对被拒：相机未进入配对等待时连接，界面显示原因且不快速重试。
- 停止：在等待配对确认、Sony 初始化和连续取景三个阶段分别按 `s`，均在 1 秒内停止。
- 相机断电、关闭 Wi-Fi、远离热点：界面显示原因，按退避间隔重连，恢复后旧命令不执行。
- 手机同时连接热点：不影响相机连接和取景。
- 在相机机身修改 ISO：界面在 1 秒内更新。
- 连续快速切换曝光 Mode 10 次：最终 Mode 等于最后一次目标，界面状态正确。
- 连续运行 30 分钟：记录最低 FPS、最低内部 RAM 和 PSRAM、重连次数。
