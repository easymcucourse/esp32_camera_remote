# Wi-Fi 热点需求

本文定义 LCD 主机创建的 Wi-Fi 热点（供相机连接）的配置管理需求及验收标准。

> 配置校验 / NVS / 异步应用任务、串口修改与只重置热点、连接页 IP / 密码开关已接入，已完成基础构建与实机回归。手柄热点页已接入代码，两级重置已有代码，网页入口仍待实现；全部重置的实机效果待验收。当前配置以屏幕与 wifi show 为准。

## 当前实现

热点由 `main/wifi_ap.c` 创建，默认值在 `main/wifi_config.h` 中定义，用户配置由本项目单独保存：

| 项目 | 当前值 |
| --- | --- |
| 默认 SSID | `easycamctrl` |
| 密码 | `00000000` |
| 加密 | WPA2-PSK，不要求 PMF |
| 信道 | 6 |
| 最大客户端数 | 4 |
| AP 地址 | `192.168.4.1/24`，内置 DHCP 服务 |
| Wi-Fi 配置存储 | 应用记录保存至 NVS `wifi_ap/cfg`，驱动使用 RAM（`WIFI_STORAGE_RAM`） |
| 连接页显示 | SSID、按显示开关处理的密码、网络接口读取的 IP |
| RSSI 显示 | 按目标相机 MAC 查找关联客户端 |

串口配置已实测；手柄热点页视觉与操作、网页入口、NVS 故障恢复及全部重置实机验收尚待完成，详见 [实施状态](../development/implementation-status.md)。

所有设备默认使用相同的简单密码是有意的选择：相机屏幕键盘输入困难，固定的 `00000000` 最容易输入。需要更高安全性的用户自行修改密码（R2）。

## 需求

### 1. 默认配置

- **R1.1** 默认密码固定为 `00000000`，所有设备相同，减少在相机上的输入难度。
- **R1.2** 默认 SSID 为 `easycamctrl`。
- **R1.3** 默认信道保持 6，加密保持 WPA2-PSK。

### 2. 修改配置

- **R2.1** 支持修改 SSID、密码和信道。
- **R2.2** 校验规则：SSID 1–32 字节；密码 8–63 个可打印 ASCII 字符；信道 1–13。不合法的输入拒绝保存并提示原因。
- **R2.3** 修改入口：
  - 串口命令（开发和维护使用），格式待定；
  - 手柄设置菜单（普通用户使用），在 [界面显示方案](ui-request.md) 的设置菜单中增加热点设置页。密码输入方式待定，可提供“重新生成随机密码”代替逐字输入；
  - 网页维护页面（用手机或电脑输入任意 SSID 和密码），见 [维护页面需求](maintenance-request.md)。
- **R2.4** 保存后重启热点生效；界面提示相机需要重新连接新热点。已保存的相机配对身份不受影响。

### 3. 持久化

- **R3.1** 热点配置保存到 NVS，断电和常规烧录后保持。
- **R3.2** NVS 中的配置损坏或缺失时，回退到默认配置并记录日志，不得无法启动。

### 4. 显示

- **R4.1** 连接页显示 SSID 和密码，供相机连接时参考。
- **R4.4** 开机后连接页显示 LCD 的 IP 地址（当前为 `192.168.4.1`），供维护页面访问和排查网络问题时参考。地址从网络接口读取，不在界面代码中写死；热点启动前显示 `IP: --`。
- **R4.2** 提供“在屏幕上显示密码”开关；关闭时密码显示为 `********`。默认开启。
- **R4.3** 状态栏的 Wi-Fi RSSI 取目标相机的值；相机未连接时显示 `WIFI --`。

### 5. 恢复出厂设置

- **R5.1** 提供恢复出厂设置入口，可选择：
  - 只重置热点配置；
  - 重置热点配置和相机配对身份（全部恢复出厂）。
- **R5.2** 恢复出厂设置需要二次确认，避免误操作。
- **R5.3** 无法进入界面时，可通过烧录工具擦除 NVS 恢复，方法见 [故障排查与恢复](../user-guide/troubleshooting.md)。

## 验收测试

- 首次启动和恢复出厂设置后，SSID 为 `easycamctrl`，密码为 `00000000`，信道为 6。
- 通过串口和手柄菜单分别修改 SSID、密码、信道，重启热点后相机能用新参数连接。
- 输入 7 位密码、33 字节 SSID、信道 14，均被拒绝并提示原因。
- 断电重启后配置保持；人为写坏 NVS 中的配置后，设备以默认配置启动并记录日志。
- 关闭“显示密码”后连接页显示 `********`。
- 开机后连接页显示 `IP: 192.168.4.1`；修改热点参数并重启热点后仍正确显示。
- 相机和手机同时连接热点时，RSSI 显示的是相机的值。
- 只重置热点配置后，相机连上新热点无需重新配对；全部恢复出厂后需要重新配对。
