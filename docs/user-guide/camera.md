# 相机连接

当前适配目标为 Sony ZV-E10。LCD 建立 Wi-Fi 热点，相机加入热点后，通过 TCP 15740 的命令、事件两条连接运行 PTP/IP。源码当前行为见 [连接设计](../design/sony-ptpip-design.md#当前实现连接与运行)，功能目标见 [相机连接需求](../request/sony-ptpip-request.md)。

LIVE 右上角显示相机电量及对焦模式，SETTINGS 右上首行也显示两者；屏幕不显示手柄电量，DS 手柄电量改用 Matrix 第一行。未知相机电量显示 `--`，≤20% 标红。单帧损坏保留最后画面并继续取景，连续十帧损坏后重连；LCD 同步失效最多尝试三次重建，耗尽后停止相机并软重启。本轮代码尚待烧录和实机验收。

## 连接步骤

1. 启动 LCD，连接页显示热点名称、密码、ATOM 与手柄状态。默认 SSID 为 **easycamctrl**，密码 **00000000**，信道 6；已保存的热点配置优先，以屏幕和串口 `wifi show` 为准。默认值位于 `main/wifi_config.h`。连接页和热点设置页的黄色 `DEFAULT` 表示仍使用出厂密码；隐藏密码时也保留该提示。
2. 相机连接该热点，启用 PC 远程功能，并选择 Wi-Fi 接入点连接。
3. 首次连接时进入相机的配对等待画面；若出现确认提示，允许 **ESP32-Camera-Remote**。LCD 生成并保存 GUID，后续连接复用此身份。
4. 双通道建立、会话打开及 Sony 初始化完成后等待取景。第一帧成功解码后进入 LIVE，上下各留 12 像素黑边。
5. 如需诊断，用串口 `p` 验证配对及同 GUID 重连；诊断成功后用 `j` 启动取景。运行期间用 `s` 停止，用 `j` 恢复。

已保存绑定时显示重连提示并使用较短超时。旧固件只保存 GUID 的记录会保留原身份；第一次完整 Sony 初始化成功后补存相机绑定。

## 地址与配置位置

| 项目 | 当前配置 | 源码位置 |
|---|---|---|
| LCD 热点网关 | `192.168.4.1` | 当前 SoftAP 网络配置 |
| 相机 IP | DHCP 租约中的实际地址 | `wifi_ap_get_clients` 自动获取 |
| 相机绑定 | 首次成功后保存 MAC 和相机 GUID | `sony_remote/peer` |
| 热点名称 / 密码 / 信道 | NVS 保存值，缺失时用默认值 | `wifi_ap/cfg`；默认值在 `main/wifi_config.h` |
| 配对身份 | NVS 持久化 GUID | `sony_remote` / `guid` |

相机 IP 随 DHCP 租约变化，不需改源码。尚未配对时只连接一台具有 TCP 15740 服务的相机；多个候选会提示先断开多余设备。更换相机时先 `s`，等日志 `Camera task finished`，再 `u` 清除绑定，最后 `j/p` 重新确认。`u` 仅清除相机身份，不擦除整片 Flash。PC 抓包中的 `192.168.110.46` 属于另一网络。

## 已接入功能

- 动态发现、配对身份及相机绑定持久化、同身份重连、连续取景；属性变化事件触发刷新，并保留约 5 秒轮询。
- Y / 三角切下一曝光 Mode，X / 方块切下一对焦模式；连续输入合并目标，等待相机回读确认。
- Start 或串口 `S` 切换设置页；基础参数在右栏，新增拍摄参数在缩略图下方。
- L1/R1 为 Wide / Tele；仅确认非电动变焦镜头且 MF 时替代为近 / 远对焦。当前用户确认电动变焦镜头，不启用该替代分支。
- LT / RT 半压合并为 S1，LT 全压请求录像目标，RT 全压触发 S2；七项参数与热点菜单已接入，操作见 [手柄手册](controller.md)。

新增固件已烧录；连接、配对保存、取景、停止及重启恢复已实测，见 [验收记录](../records/connection-test-20261001.md)。新映射的相机动作、菜单参数效果及扩展参数视觉验收仍待完成，最新代码状态见 [实施状态](../development/implementation-status.md)。无线闪光和白平衡 AB/GM 微调暂显示原始编码；WB 色温是相机返回的保存值，不保证当前白平衡模式正在使用它。拍照、录像、变焦及七项参数写入已有代码和主机回归，实际相机效果仍待逐项验收。

## 连接失败时

- 停在“等待相机”：检查相机是否加入 LCD 热点且取得 DHCP 租约、PC 远程是否启用；已绑定时只寻找保存的相机。
- TCP 连接失败：核对相机 IP、PC 远程模式和 TCP 15740 服务是否可用。
- 停在配对确认：检查相机配对等待画面和授权提示。首次 InitCommandAck 最长等待 120 秒，已绑定为 10 秒；`s` 可取消网络等待。
- 取景断开：按 1–30 秒退避重试；相机拒绝初始化时暂停自动重试，确认相机后用 `j/p`。保存串口中失败阶段、操作码及事务号，再对照 [抓包分析](../records/protocol-analysis-20261001.md)。

更多恢复步骤见 [故障排查](troubleshooting.md)，命令见 [串口手册](serial.md)，抓包方法见 [抓包工具](../tools/capture.md)。
