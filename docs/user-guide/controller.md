# 手柄

M5Stack ATOM Matrix 通过经典蓝牙连接 DualShock 4，再经 I²C 把按键状态上报给 LCD。接线、蓝牙配对和当前协议版本 1 见 [ATOM 子项目](../../m5_atom_matrix/README.md)。

## 接线

LCD GPIO8（SDA）、GPIO9（SCL）、GND 连接 ATOM GPIO26、GPIO32、GND。总线 100 kHz，上拉到 3.3 V，ATOM 从机地址 `0x42`。两端分别 USB 供电时不要连接 Grove 5V。

修改 I²C 协议需要同时烧录 LCD 和 ATOM。只改 LCD 界面或相机控制时，只更新 LCD。

## 配对

首次配对按住 SHARE + PS，直到灯条快闪。已经保存过配对时，按 PS 唤醒。

ATOM 绿灯只表示 LCD 与 ATOM 的 I²C 已经建立。DS4 是否可用，以串口日志 `DualShock 4 connected; input ready` 和按键是否生效为准。

## 已实现的按键

| 手柄按键 | 功能 |
| --- | --- |
| Start / Options | 切换设置与预览界面 |
| L1 | 循环切换上一个曝光 Mode |
| R1 | 循环切换下一个曝光 Mode |
| X / 方块 | LIVE+MF+变焦不可用时近对焦，发送 +1 |
| Y / 三角 | LIVE+MF+变焦不可用时远对焦，发送 −1 |
| 其他按键 | 只在串口上报按下和松开，尚未绑定相机操作 |

Start、L1/R1 按住不会重复触发。同一次事件里同时按下 L1 和 R1 时不切换。未连接相机、属性只读或没有有效枚举时，只记录原因，不改变 Mode。

X/Y 单击一步，按住 400 ms 后每 150 ms 请求下一步，实际发送速度受相机事务速度限制，不积压步数。两键同时按下取消重复，必须都松开再按。松开、进入设置、切 AF、变焦可用或断线时取消未执行的对焦。连接时已按住的键必须先松开；不需要打开对焦框。

## 已知限制

相机对设置应答 `0x2001` 只表示请求已被接受。紧接着回读仍可能是旧 Mode，大约 5 秒后的属性查询才会显示新值。连续快速按 L1/R1 可能按旧值重复设置同一个目标。

按键事件缓存在 ATOM 的 RAM 里，最多 128 次变化，ATOM 重启后清空。超过 128 次时丢掉最旧的事件，并在日志里记录溢出。

计划中的拍照、对焦、变焦和云台操作见 [手柄控制方案](../request/gamepad-request.md)。

X/Y 对焦已接入 LCD 代码并经过主机测试，尚待烧录后的实机验收。正值向近处由用户确认；相机完整属性中须有 Focus=MF、ZoomEnableStatus=0，属性缺失、解析失败或状态过期时不发送。每步发送前重新查询属性。其他条件下 X/Y 的放大/信息显示仍为规划功能，当前不会触发这些操作。
